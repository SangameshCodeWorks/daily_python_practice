## 🔮 Upcoming Learning Modules (Curriculum Roadmap)

### Phase 1: Advanced Control Flow & Iteration
- [ ] **Multi-Way Decision Making:** `if - elif - else` ladders, grade calculators, BMI calculators.
- [ ] **Nested Conditional Statements:** Inner `if` blocks, account access validation, nested boundaries.
- [ ] **Structural Pattern Matching:** Modern Python 3.10+ `match - case` statements.
- [ ] **While Loops:** Conditional looping, counter increments, infinite loops, and sentinel-controlled loops.
- [ ] **For Loops & Ranges:** `for item in sequence`, `range(start, stop, step)`, reverse loops.
- [ ] **Loop Control Statements:** `break` (early exit), `continue` (skip iteration), `pass` (placeholder), and `else` clause in loops.
- [ ] **Iterating Over Multi-Dimensional Data:** Looping over nested lists, dictionary `.items()`, `enumerate()`, `zip()`.

### Phase 2: Functions & Functional Programming
- [ ] **Function Fundamentals:** `def` keyword, docstrings, calling functions, parameters vs arguments.
- [ ] **Argument Types:** Positional arguments, keyword arguments, default parameter values.
- [ ] **Variable-Length Arguments:** Arbitrary positional arguments (`*args`), arbitrary keyword arguments (`**kwargs`).
- [ ] **Return Statements:** Returning single values, multiple values (tuples), early returns.
- [ ] **Variable Scope & Namespaces:** Local, Enclosing, Global, Built-in (LEGB rule), `global` and `nonlocal` keywords.
- [ ] **Lambda Functions:** Anonymous inline functions, sorting with `key=lambda x: ...`.
- [ ] **Higher-Order Functions:** Built-in `map()`, `filter()`, and `functools.reduce()`.

### Phase 3: Comprehensions & Advanced Data Techniques
- [ ] **List Comprehensions:** `[expression for item in iterable if condition]`.
- [ ] **Dictionary & Set Comprehensions:** `{k: v for ...}`, `{x for ...}`.
- [ ] **Generator Expressions & Generators:** `yield` keyword, memory-efficient streaming of large sequences.

### Phase 4: Error Handling & File I/O
- [ ] **Exception Handling:** `try`, `except`, `else`, `finally` blocks.
- [ ] **Handling Specific Exceptions:** `ValueError`, `KeyError`, `IndexError`, `TypeError`, `ZeroDivisionError`.
- [ ] **Custom Exceptions:** Defining custom exception classes inheriting from `Exception`, raising with `raise`.
- [ ] **File Operations:** Reading and writing text files (`open()`, mode `'r'`, `'w'`, `'a'`).
- [ ] **Safe Resource Management:** `with open(...) as f` context managers.

### Phase 5: Object-Oriented Programming (OOP)
- [ ] **Classes & Instances:** `class` syntax, instance attributes, `__init__()` constructor, `self`.
- [ ] **Instance, Class & Static Methods:** `@classmethod`, `@staticmethod`, `cls`.
- [ ] **Encapsulation & Access Modifiers:** Public, protected (`_`), and private (`__`) attributes, `@property` getters/setters.
- [ ] **Inheritance & Polymorphism:** Single inheritance, multiple inheritance, `super()`, method overriding.
- [ ] **Magic / Dunder Methods:** `__str__`, `__repr__`, `__len__`, `__eq__`, `__add__`.
